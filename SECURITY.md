# Security Policy

## Supported versions

Security fixes are provided for the latest stable release only. Older releases
may no longer receive security updates; upgrade to the latest release before
reporting an issue if you can do so safely.

| Version | Supported |
| --- | --- |
| Latest stable release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Use
[GitHub's private vulnerability reporting](https://github.com/greyfoxdevelopment/GFDev-StarRail-Companion/security/advisories/new)
if it is available for this repository. Do not open a public issue or pull
request containing details that could put users at risk.

If private reporting is unavailable, contact the repository maintainers through
GitHub and ask for a private channel before sharing technical details.

Include, where possible:

- The affected release, component, and platform.
- A concise description of the impact and conditions required.
- Reproduction steps or a proof of concept that does not access other users'
  data or services without authorization.
- Any suggested mitigation.

Please allow maintainers a reasonable opportunity to investigate and prepare a
fix before publicly disclosing the issue. We aim to acknowledge reports within
five business days and provide an update within ten business days. These are
targets, not guarantees; investigation and release timing can vary.

## Scope

Reports are in scope when they identify a security issue in this project's
Windows application, installer, updater, or release automation. Issues solely
in third-party services or software are out of scope, but a vulnerability in
how this project interacts with them may be in scope.

Please do not include Warp-history links, account credentials, local cache
files, or other personal data in a report unless strictly necessary. Redact
such information from logs and screenshots; a valid Warp-history link may
grant access to private Warp history.
